# SquareSolver's user manual
#ininglish

Этот проект предназначен для нахождения корней у многочленов не старше второй степени и их графического представления.

Проект создан в рамках образовательного пред-семестрового курса МФТИ ФРКТ "Летняя школа",
организованного [Ильей Рудольфовичем Дединским](https://ded32.net.ru/).

Проект создан на операционной системе MacOS. На иных платформах возможна некорректная работа.


## Установка и запуск:
1) Скачайте архив с проектом, распакуйте в произвольную директорию.
2) Если у вас не установлен компилятор языка С++ -- g++, установите его.
3) Для создания графического представления графика соответствующего многочлена в программе
используется библиотека RayLib. Вам необходимо установить ее с официального сайта.
4) В терминале прейдите в папку с проектом ->/src
5) Запустите файл comp.sh
6) Запустите файл SquareSolver
7) При запуске без параметров, программа опишет свой функционал и предоставит список параметров запуска
8) Чтобы применить параметр, после запуска программы укажите их. Пример:
"./SquareSolver -r -pr"
9) Готово!


## Описание функционала:
### Тестирование
Программа способна проводить тестирование своего алгоритма решения уравнения не старше второго порядка
получая данные из встроенного в программу списка тестов, внешнего файла или генерируя случайные величины самостоятельно.

**Флаги запуска:**
```
-rt (количество тестов) -- запуск тестов со случайными коэффициентами
-st                     -- запуск системных тестов
-ft (путь к файлу)      -- запуск тестов из файла
```

### Решение пользовательских уравнений
1. Программа может запрашивать данные у пользователя. Есть возможность по заданным коэффициентам
построить график полученной функции, перемещаться по нему и масштабировать.
Программа самостоятельно подбирает масштаб графика, так, чтобы функция находилась в пределах экрана
и ее расположение относительно осей было понятно пользователю.

**Команды для перемещения по графику и изменению его масштаба:**
```
- 'w', 'a', 's', 'd' для перемещения
- 'e', 'q' для масштабирования всего графика
- 'x' + 'up', 'x' + 'down' для масштабирования оси x обособленно
- 'y' + 'up', 'y' + 'down' для масштабирования оси y обособленно
- 'h' (home) для перемещения к началу координат
- 'm' для возврата автоматического масштаба
```
**Флаги запуска:**
```
-r / -run_AI -- запуск диалога с пользователем и нахождение корней по введенным коэффициентам
-pr          -- при добавлении этого параметра будет отображен интерактивный график функции
```
2. Программа может получать данные из файла и выводить решение в терминал
(вывод решения в файл в разработке)
Для этого ей необходимо указать путь к файлу.

**Флаги запуска:**
```
-f (путь к файлу) -- запуск решения по коэффициентам из файла (коэффициенты разделяются ";")
```
!!! В программе стоит ограничение на количество уравнений в одном файле - MAX_NUM_OF_EQ_FROM_FILE
Если количество уравнений в вашем файле превышает данное количество, необходимо его увеличить
или разделить один файл на файлы меньшего размера.
